*v0.1 실제 UI의 예제 데이터 기반 브라우저 미리보기이며 네이티브 실행 검증 화면은 아닙니다.*

## 로컬 자막 준비
일반 필기는 Python 없이 작동합니다. 자막은 **엔진 설치 → 모델 다운로드 → 자막 시작** 순서로 준비합니다. 엔진과 모델을 준비하는 동안에는 마이크나 PC 소리를 수집하지 않습니다.

1. **Python 3.10 이상**을 먼저 설치합니다. 앱의 엔진 설치를 사용하려면 Windows의 `python` 또는 macOS/Linux의 `python3`을 Pointory에서 찾을 수 있어야 합니다. 앱은 Python 자체를 설치하지 않습니다. 자세한 설치·경로 설정은 [STT 설정](../../docs/STT-SETUP.md)을 참고하세요.
2. 툴바의 **자막 아이콘** 또는 설정의 **실시간 자막**을 엽니다. **Local Whisper**와 모델, 연산 장치를 선택합니다. 기본 `base`는 약 148 MB, 더 작은 `tiny`는 약 78 MB의 모델 파일을 받습니다. 엔진 패키지에는 추가 용량이 필요합니다.
3. 엔진이 없다고 나오면 **음성 엔진 설치**를 실행합니다. 앱 전용 Python 환경에 필요한 패키지가 설치됩니다. Intel OpenVINO나 Qwen을 선택하면 해당 엔진 패키지도 필요합니다.
4. **모델 다운로드**를 실행합니다. 모델 출처·라이선스, 예상 용량, 저장 경로와 준비 상태를 확인합니다. 이미 호환 모델이 있는 경우 모델 입력란에 로컬 폴더 경로를 지정할 수 있습니다.
5. 모델 준비가 완료되면 발화 언어, 마이크/PC 재생 소리와 실제 오디오 장치를 선택합니다. 마이크를 연결한 뒤 **장치 새로고침**을 누릅니다.
6. **자막 시작**을 누르고 말한 뒤 자막과 실제 사용 장치를 확인합니다. 중지하거나 자막 설정 창을 닫으면 오디오 캡처를 해제합니다. OpenVINO는 최초 시작 시 로컬 모델 컴파일로 시간이 더 걸릴 수 있습니다.

자동은 탐지된 지원 가속 장치에서 선택하며, 사용 가능한 가속 장치가 없으면 CPU를 선택합니다. 준비할 모델과 자막 시작에 같은 장치를 사용합니다. GPU/NPU 초기화가 실패하면 **CPU를 선택하고 그 모델을 준비한 뒤 다시 시작**하세요. 엔진 설치는 GPU 드라이버를 설치하지 않습니다.

![모델 준비 완료 후 자막을 시작할 수 있는 상태](../assets/model-ready.png)

`POINTORY_STT_PYTHON` 또는 이전 이름의 Python 환경 변수를 직접 지정한 경우 **음성 엔진 설치**는 `runtime_override`를 표시합니다. 지정한 환경에 `stt/requirements.txt`와 필요한 엔진 패키지를 직접 설치하거나, 모든 Python 경로 지정을 해제하고 Pointory를 다시 실행한 뒤 앱 전용 환경을 준비하세요. [사용자 지정 Python 환경](../../docs/STT-SETUP.md#custom-python-environments)에서 자세히 설명합니다.

## 다운로드 취소·재개와 저장 위치

![완료된 파일 기준으로 표시되는 모델 다운로드 진행 상태](../assets/model-download.png)

다운로드 도중 **취소**를 누르면 준비 작업이 중지됩니다. 완료된 파일과 재개용 데이터는 유지되며 다시 다운로드하면 호스트가 지원하는 범위에서 이어받습니다. 진행률은 완료된 파일을 기준으로 계산하므로 큰 모델 파일을 받는 동안 한동안 움직이지 않을 수 있습니다. 취소되거나 덜 받은 모델은 준비 완료로 표시하지 않습니다.

새 모델은 기본적으로 사용자 홈의 `~/.cache/pointory/` 아래에 저장됩니다. 예를 들어 Whisper base는 `whisper-base`, OpenVINO base는 `ov-whisper-base`입니다. 이전 Hugging Face·OnPen·LayerPen 캐시에 호환되는 완성 모델이 있으면 그대로 재사용합니다. 저장 경로 변경은 [STT 설정](../../docs/STT-SETUP.md#model-storage)을 참고하세요.

자막 설정 창을 닫아도 다운로드·엔진 설치는 계속됩니다. 다시 열면 진행 상태를 볼 수 있습니다. **취소**하거나 Pointory 앱을 종료하면 준비 작업도 중지됩니다.

## GPU·NPU 범위
Whisper는 CPU, 선택적 CUDA, 드라이버·패키지·모델이 호환되는 Intel OpenVINO GPU/NPU 경로를 제공합니다. NPU가 있다는 이유만으로 모든 모델을 실행할 수는 없습니다. OpenVINO는 구현된 tiny/base/small 경로를 지원하고 Qwen 로컬 CPU는 실험적입니다. Apple Metal/Core ML/ANE 가속은 이번 버전에서 구현·검증되지 않았습니다.

## API 제공자
![API 키를 입력하지 않은 클라우드 제공자 설정](../assets/captions-api-setup.png)

API 제공자는 **로컬 모델 다운로드가 필요 없습니다**. Python 워커 의존성이 없으면 API 제공자를 선택한 화면에 **음성 엔진 준비**가 표시됩니다. 여기서 **음성 엔진 설치**를 실행하면 되며 제공자를 바꿀 필요가 없습니다. Python 경로를 직접 지정했다면 해당 환경에 의존성을 직접 설치합니다. API 키와 계정에서 사용 가능한 모델을 입력한 뒤 오디오 장치를 선택하고 시작합니다. 음성은 해당 제공자로 전송됩니다. 키는 현재 실행에만 사용하며 설정에 저장하지 않습니다. 접근 권한·모델 호환성·과금은 계정에 따라 다르고 이번 릴리스에서는 실제 유료 키로 검증하지 않았습니다.

## 문제 해결
엔진 설치가 안 되면 Python 경로, 인터넷 연결과 디스크 여유 공간을 확인합니다. 모델 다운로드가 끊겼으면 같은 모델로 다시 시도합니다. 자막이 없으면 장치·마이크 권한·음성 감지 기준을 확인합니다. 가속 장치가 없으면 드라이버와 선택 런타임을 확인합니다. 모델 변경 전 자막을 중지하세요. 스크린샷은 미리보기이며 실제 음성·하드웨어 성공 결과가 아닙니다. 오디오 녹음 파일은 저장하지 않습니다.
