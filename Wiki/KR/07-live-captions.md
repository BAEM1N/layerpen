## 로컬 자막 준비
일반 필기는 Python 없이 작동합니다. 자막은 [STT 설정](../../docs/STT-SETUP.md)에 따라 워커 의존성을 설치합니다. Windows 설정 스크립트는 별도 Pointory Python 환경을 만들며 모델은 최초 내려받기가 필요할 수 있습니다.

1. 툴바 **CC** 또는 설정의 실시간 자막을 엽니다.
2. Local Whisper와 모델을 선택합니다. 작은 지원 모델부터 시작하세요.
3. 자동 또는 탐지된 연산 장치를 고릅니다. 자동은 CPU로 대체할 수 있지만 명시적으로 선택한 미지원 장치는 오류를 표시합니다.
4. 발화 언어, 마이크/PC 재생 소리, 실제 오디오 장치를 선택합니다. 마이크를 연결한 뒤 장치 새로고침을 누릅니다.
5. 시작을 누르고 말한 뒤 자막과 실제 사용 장치를 확인합니다. 중지하거나 자막 설정 창을 닫으면 오디오 캡처를 해제합니다.

## GPU·NPU 범위
Whisper는 CPU, 선택적 CUDA, 드라이버·패키지·모델이 호환되는 Intel OpenVINO GPU/NPU 경로를 제공합니다. NPU가 있다는 이유만으로 모든 모델을 실행할 수는 없습니다. OpenVINO는 구현된 tiny/base/small 경로를 지원하고 Qwen 로컬 CPU는 실험적입니다. Apple Metal/Core ML/ANE 가속은 이번 버전에서 구현·검증되지 않았습니다.

## API 제공자
![API 키를 입력하지 않은 클라우드 제공자 설정](../assets/captions-api.jpg)

제공자를 고르고 API 키와 계정에서 사용 가능한 모델을 입력한 뒤 오디오 장치를 선택하고 시작합니다. 음성은 해당 제공자로 전송됩니다. 키는 현재 실행에만 사용하며 설정에 저장하지 않습니다. 접근 권한·모델 호환성·과금은 계정에 따라 다르고 이번 릴리스에서는 실제 유료 키로 검증하지 않았습니다.

## 문제 해결
자막이 없으면 장치·마이크 권한·음성 감지 기준을 확인합니다. 가속 장치가 없으면 드라이버와 선택 런타임을 확인합니다. 모델 변경 전 중지하세요. 스크린샷은 미리보기이며 실제 음성·하드웨어 성공 결과가 아닙니다. 오디오 녹음 파일은 저장하지 않습니다.
