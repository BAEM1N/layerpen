# 커서 스포트라이트와 원형 확대

[Pointory](../../README.ko.md) · [사용 가이드](README.md) · [English](../EN/11-spotlight.md)

![Pointory 스포트라이트 설정](../assets/spotlight-settings.jpg)

*실제 설정 UI의 브라우저 미리보기입니다. 아래 이미지는 실제 스포트라이트 표시 코드를 예제 수업에 적용한 밝기 강조 미리보기이며 네이티브 확대 동작의 검증 화면은 아닙니다.*

## 켜고 사용하기

1. 필기할 모니터를 선택합니다.
2. 툴바의 원형 빛 모양 **스포트라이트** 버튼 또는 설정의 **켜기 / 끄기**를 누릅니다.
3. 마우스를 움직이면 밝은 원이 커서를 따라갑니다. 나머지 부분은 어두워집니다.
4. 아래 슬라이드나 앱을 클릭하려면 마우스 모드를 사용합니다. 필기 모드에서는 기존대로 필기합니다.
5. **Esc** 또는 같은 스포트라이트 버튼으로 끕니다. 스포트라이트가 켜진 동안에는 다른 앱을 조작하고 있어도 Esc로 끌 수 있도록 전역 키를 임시 등록합니다. 끄면 일반 Esc 입력으로 돌아갑니다. 선택 모니터를 바꾸면 중지됩니다. 다른 모니터로 커서가 나가면 효과를 숨깁니다.

다른 프로그램이 Esc를 예약했거나 데스크톱 환경에서 전역 키 등록을 지원하지 않으면 안내가 표시됩니다. 이때는 Pointory 툴바에 포커스를 둔 뒤 Esc를 누르거나 스포트라이트 버튼으로 끄세요. Linux Wayland의 창 배치·전역 단축키 동작은 지원 대상이 아닙니다.

## 원 크기·밝기·배율

| 설정 | 범위 | 용도 |
| --- | --- | --- |
| 원 반경 | 40–300 논리 픽셀 | 작은 아이콘부터 문장까지 강조 범위 조절 |
| 바깥 어둡기 | 10–90% | 배경 정보가 얼마나 보일지 조절 |
| 원 안 확대 | 1 / 1.5 / 2 / 3배 | 1배는 밝기 강조만, 나머지는 원형 돋보기 |

설정은 다음 실행에도 유지되지만 스포트라이트가 자동으로 켜지지는 않습니다. 기존 영역 확대(Z)는 화면을 멈춰 전체 영역을 확대하는 별도 기능입니다.

## 지원과 공유

Windows에서는 원 안의 화면을 반복 캡처해 확대합니다. 커서 위치는 더 자주 갱신하고 확대 이미지는 약 125 ms 이상의 간격으로 갱신하므로 빠른 이동이나 동영상에는 지연이 있습니다. 화면 가장자리에서는 확대 소스 영역을 화면 안으로 제한합니다. 화면 캡처 차단 콘텐츠는 정상 확대되지 않을 수 있습니다.

Mac·Linux는 현재 확대 없이 밝기 강조만 적용하며 네이티브 실행 검증이 남아 있습니다. Windows의 자기 화면 재캡처를 방지하기 위해 효과 창은 캡처에서 제외합니다. Pointory의 LAN 실시간 보기에는 효과를 다시 합성합니다. 일반 PNG/GIF와 다른 회의·녹화 앱에 효과가 보인다고 보장하지 않습니다. 실제 모니터·배율·프로젝터·수강생 기기로 확인하세요.

이는 Logitech 장치 연결이나 전용 버튼 연동이 아니며 일반 마우스 커서를 사용하는 독립 구현입니다.
