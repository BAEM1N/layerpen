# Pointory illustrated user guides

**[한국어 사용 가이드](KR/README.md)** · **[English user guides](EN/README.md)** · [Download](https://github.com/BAEM1N/pointory/releases/latest)

Guides for screen annotation, text fonts, configurable toolbars, PNG/GIF export, optional captions, and classroom sharing. These files live in the repository's `Wiki` folder and can be read or contributed to with normal pull requests.

Screenshots use actual app UI with sample content. See [capture provenance](assets/README.md) for the distinction between browser preview, HTTP fixture testing, and native runtime verification.
