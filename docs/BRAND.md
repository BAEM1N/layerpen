# Pointory · 포인토리

Pointory is a lightweight screen annotation and live-caption tool for teachers, presenters, and demos. It also provides cursor spotlight and experimental classroom material sharing. Use **Pointory** for the product name and **포인토리** as the Korean name.

- Repository: `BAEM1N/pointory`.
- Windows installer: `Pointory_0.1.0_x64-setup.exe`.
- Portable archive: `Pointory-0.1.0-windows-x64-portable.zip`; launch `Pointory.exe` inside it.
- Source package and native binary: `pointory`.
- Preferred domain: `pointory.app`. As of 2026-09-09, it has **not been purchased, connected, or deployed**. Treat it as a planned domain, not a working product website.
- App themes: blue (default), teal, green, orange, and purple. Drawing colors are independent.

Earlier versions used OnPen and LayerPen. Historical validation records keep the names that were actually tested. The internal identifier `dev.personal.monitorink` remains for upgrade compatibility. Pointory migrates legacy settings, imported fonts, and default capture preferences without moving existing exports or changing custom capture folders. See [development notes](DEVELOPMENT.md) for environment-variable aliases.
