# OnPen discoverability

The repository describes a real product category: open-source screen annotation for teaching and presentations, with typed text, spotlight, optional live captions, and experimental classroom LAN sharing. English and Korean entry points link to feature-specific guides with descriptive screenshot alt text, concrete steps, FAQs, and explicit platform limits.

GitHub topics and a concise repository description help categorization. Real license, release, CI, and star badges lead to their underlying evidence. Downloads and contribution paths appear near the top of the README. No invented user counts, testimonials, benchmark claims, or keyword stuffing are used.

These changes do not guarantee stars, search position, or citations by AI systems. Google's [AI optimization guidance](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide) emphasizes useful, accessible content and foundational SEO rather than a special AI schema. GitHub renders the README; this repository does not control GitHub's canonical tags, robots policy, or page metadata. A future independent website would need its own technical SEO and verification.

When a replacement demo is ready, use a descriptive still-image link in the README pointing to a stable video page. Add a text transcript and matching guide links. Keep generated illustrative footage distinct from evidence of actual UI behavior.
