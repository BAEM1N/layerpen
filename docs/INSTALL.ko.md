# Pointory 0.1.0 설치

Windows x64용입니다. [GitHub Releases](https://github.com/BAEM1N/pointory/releases)에서 받으세요.

- 설치형: `Pointory_0.1.0_x64-setup.exe` 실행. 현재 사용자용 설치이며 한국어·영어·일본어·중국어 간체를 지원합니다.
- 포터블: `Pointory-0.1.0-windows-x64-portable.zip` 압축을 풀고 `Pointory.exe` 실행.

Microsoft WebView2 Runtime이 필요합니다. 설치형은 없을 경우 다운로드를 시도하며 인터넷이 필요합니다. 포터블도 WebView2가 필요합니다. 포터블은 설치 생략형이며 설정은 설치형과 동일한 사용자 설정 폴더에 저장합니다.

설치파일은 서명되지 않았으며 자동 업데이트는 없습니다. 기존 OnPen·LayerPen·Monitor Ink와 Pointory는 종료한 뒤 실행하세요. 이전 내부 버전보다 공개 버전 번호가 작으므로 기존 설치본을 제거한 뒤 새로 설치하는 것을 권장합니다. 이전 설정과 가져온 글꼴은 이어받습니다. 기본 캡처 경로는 Pictures/Pointory로 전환하되 기존 파일은 이동하지 않으며 직접 지정한 폴더는 유지합니다.

제거는 Windows 설정 → 앱 → Pointory에서 진행합니다. 앱 데이터 삭제 옵션을 선택하지 않으면 설정을 보존합니다. 판서와 GIF 기록은 앱 종료 시 사라지므로 필요한 결과는 먼저 저장하세요.
