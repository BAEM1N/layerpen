# Pointory Mac 현장 확인

토요일 현장에서 Mac 바탕화면에 로그인한 뒤 최신 미리보기의 실제 조작을 확인하는 순서입니다. 현재 앱 버전은 **0.1.0**, 배포물은 **0.1.0-preview**이며 v0.2 출시를 준비하는 단계입니다. 이 체크리스트 자체는 검증 완료 기록이 아닙니다. 완료한 원격 검사와 이전 실기 결과는 [Mac 검증 기록](validation/0.2-macos.ko.md)에서 확인합니다.

## 준비 폴더와 실행 순서

Mac의 바탕화면에 준비한 `Pointory-Check` 폴더를 사용합니다. 테스트 설정은 일반 사용 설정과 분리합니다. 자동 검사와 수동 확인도 서로 다른 설정 폴더를 사용합니다.

| 실행 파일 | 용도 |
| --- | --- |
| `Run Basic Checks.command` | 새 테스트 프로필로 검증용 앱을 실행·종료한 뒤 한 번 더 실행해 설정 유지까지 확인합니다. 1회차가 실패하면 멈춥니다. |
| `Open Results.command` | Finder에서 `Pointory-Check/results` 폴더를 엽니다. |
| `Launch Pointory.command` | 일반 앱을 수동 확인용 `profiles/manual` 설정으로 실행합니다. 이 설정은 다음 실행에도 유지됩니다. |

1. Mac에 로그인해 바탕화면이 보이는지 확인합니다. SSH 접속만 된 상태는 GUI 검증 시작 조건을 만족하지 않습니다.
2. 실행 중인 Pointory가 있으면 저장 후 앱 종료 버튼으로 닫습니다. `Run Basic Checks.command`를 더블 클릭하고 두 번의 실행·자동 종료와 완료 표시를 기다립니다. 검사 중에는 마우스나 키보드로 앱을 조작하지 않습니다.
3. `Open Results.command`로 결과를 엽니다. 실패 항목이 있으면 오류와 생성 파일을 보존합니다.
4. `Launch Pointory.command`로 아래 기본 확인을 진행합니다. 자동 검사 통과와 실제 마우스·키보드 확인을 각각 기록합니다.

실행기는 로그인 화면에서는 앱을 실행하지 않으며, 이미 실행 중인 Pointory를 자동 종료하지 않습니다. 안내에 따라 바탕화면 로그인이나 기존 앱 종료를 먼저 합니다. 수동 확인용 설정은 처음에 **필기 레이어만 저장**, **전역 단축키 끔**, 설정 글자 크기 **14 px**로 시작합니다. 수동 PNG·GIF의 기본 저장 위치는 `results/manual-captures`입니다.

앱이 macOS 경고로 실행되지 않으면 경고 문구를 기록하고 멈춥니다. 개발 미리보기는 ad hoc 서명이며 Developer ID 서명·공증된 정식 Mac 배포물이 아닙니다. 시스템 보안 설정을 일괄 해제하지 않습니다.

## 기본 확인 — 화면 기록·마이크 승인 없이

수업 자료 대신 샘플 문서나 빈 화면을 준비합니다. PNG는 **필기 레이어만**, GIF는 **투명 배경**을 선택합니다. **전체 화면 캡처·화면 배경 GIF·부분 확대·화면 공유 시작**은 아래 선택 검사에서 다룹니다.

| 항목 | 조작 | 기대 결과 |
| --- | --- | --- |
| 실행·배치 | 앱을 열고 화면 맨 위와 모서리에 선을 그립니다. | 툴바가 보이고 클릭한 위치에 필기가 생깁니다. 화면 위쪽이 메뉴 막대 높이만큼 밀리지 않습니다. |
| 가로·세로 | 방향을 두 번 전환하고 손잡이로 화면 가장자리까지 이동합니다. | 가로·세로만 제공하며 도구와 종료 버튼을 사용할 수 있습니다. 선택한 색·굵기가 유지됩니다. |
| 설정 도킹 | 설정을 연 채 툴바를 이동하고 방향을 바꿉니다. | 설정이 툴바 옆에서 따라가고, 사용 가능한 쪽으로 배치됩니다. 설정의 X는 설정만 닫습니다. |
| 설치 글꼴 | **텍스트 및 설정 글꼴**에서 한글 지원 시스템 글꼴을 선택합니다. | 설정 창의 글꼴과 이후 입력하는 텍스트의 글꼴에 선택이 반영됩니다. |
| 설정 크기 | **설정 글자 크기**를 12·14·16·18·20 px로 바꾸고 20 px에서 아래까지 스크롤합니다. | 항목 이름·입력·버튼을 읽고 조작할 수 있습니다. 펜 굵기와 툴바 크기는 그대로입니다. |
| TTF 가져오기 | 사용할 권한이 있는 한글 지원 `.ttf` 파일(32 MB 이하)을 추가해 선택합니다. | 설정과 새 텍스트에 글꼴이 적용됩니다. 시스템 전체에 설치하지 않습니다. 지원 문자는 PNG·GIF에서도 확인합니다. |
| 실제 한글 IME | T 아이콘 → 화면 클릭 → `포인토리 수업입니다`를 직접 입력합니다. 조합·백스페이스·줄바꿈을 확인합니다. | 클릭한 위치에 커서가 생기고 한글이 중복·분리되지 않습니다. Shift+Enter는 줄바꿈, 조합 종료 후 Enter는 확정, Escape는 취소입니다. |
| 캔버스 글자 크기 | 펜 굵기를 바꿔 새 텍스트를 입력합니다. 이후 설정 크기만 변경합니다. | 새 텍스트는 펜 굵기에 따라 크기가 바뀌고, 설정 크기 변경은 기존 필기나 캔버스 글자 크기를 바꾸지 않습니다. |
| 필기·편집 | 펜·형광펜·도형을 쓰고 실행 취소·다시 실행, 선택 이동, 지우개를 사용합니다. | 각 도구가 선택한 색·굵기로 작동하고 편집 결과가 맞습니다. |
| 클릭 통과·단축키 | 마우스 모드로 뒤 문서를 클릭한 뒤 다시 필기합니다. 전역 단축키는 기본 꺼짐이므로 설정에서 켠 뒤 표시된 전환 키를 확인합니다. | 아래 앱을 조작할 수 있고 필기로 돌아옵니다. 입력란에서 글을 쓸 때 도구가 갑자기 바뀌지 않습니다. 단축키 충돌은 조합과 앱을 기록합니다. |
| PNG·GIF | 필기 레이어 PNG와 투명 배경 GIF를 각각 저장하고 파일을 엽니다. | PNG에 한글·선·투명 배경이 보이고 GIF가 필기를 재생합니다. GIF는 데스크톱 동영상이 아닙니다. |
| 스포트라이트 | 켠 뒤 커서를 이동하고 원 크기·어둡기를 바꾼 뒤 끕니다. | 밝은 원이 커서를 따라가고 주변이 어두워집니다. **Mac은 밝기 강조만 지원하며 원 안의 실시간 확대는 제공하지 않습니다.** |
| 종료·저장 설정 | 필요한 필기를 내보낸 뒤 툴바 마지막 X로 종료하고 다시 실행합니다. | 앱이 종료되고 선택한 글꼴·설정 크기가 유지됩니다. 필기 자체는 앱 종료 시 유지되지 않습니다. |

한글 조합은 직접 타이핑해야 확인할 수 있습니다. 자동 검사의 문자열 입력만으로 통과 처리하지 않습니다. 여러 화면·Retina·전체화면 앱·Spaces를 사용할 현장이라면 해당 구성에서도 툴바 배치, 필기 좌표와 클릭 통과를 반복 확인합니다.

## 같은 네트워크 자료 다운로드

이 검사는 화면 기록 권한 없이 진행할 수 있습니다. 접속 주소는 현장에서 앱에 표시되는 값을 사용합니다.

1. 샘플 PDF나 텍스트 파일 하나를 **자료 공유 → 자료 추가**로 선택합니다.
2. 공유용 Wi-Fi 또는 이더넷 주소를 확인하고 **공유 시작**을 누릅니다.
3. 같은 네트워크의 휴대폰이나 다른 PC에서 QR 또는 전체 접속 주소를 엽니다.
4. 파일을 내려받아 원본 내용과 맞는지 확인합니다. 이 단계에서는 **화면 공유 시작**을 누르지 않습니다.
5. **공유 중지** 후 새 다운로드 요청이 연결되지 않는지 확인합니다. 이미 내려받은 파일은 남습니다.

다른 기기에서 파일을 받은 경우에만 LAN 다운로드를 통과로 기록합니다. Mac 자신의 브라우저 접속만 성공하면 로컬 접속으로 기록합니다. 접속 실패 시 같은 네트워크 여부·선택한 주소·기기 간 격리 설정을 확인하고, Pointory 화면의 오류와 함께 남깁니다. [자세한 공유 사용법](../Wiki/KR/10-classroom-sharing.md)

## 선택 확인 — 현장에서 해당 권한을 허용할 때만

준비한 `Launch Pointory.command`에는 원격 파일 검사에서 확인한 Whisper `tiny` 모델 캐시가 연결되어 있습니다. 마이크를 연결해 검사할 때 로컬 Whisper, 모델 `tiny`, CPU를 선택하면 같은 모델을 사용할 수 있습니다. 합성 영어 파일의 인식과 캐시 재사용은 확인했지만 실제 마이크와 한글 인식 품질은 현장에서 별도로 확인합니다.

기본 확인은 이 단계를 하지 않아도 완료할 수 있습니다. 권한을 요청하는 기능을 선택한 뒤 macOS 안내에 따라 사용자가 승인합니다.

| 항목 | 준비와 순서 | 기대 결과 |
| --- | --- | --- |
| 전체 화면 PNG·화면 배경 GIF | 화면 기록을 허용한 뒤 필요하면 앱을 다시 엽니다. 샘플 문서와 필기를 함께 내보냅니다. | 선택 모니터의 문서·필기가 포함됩니다. PNG에서는 툴바가 제외되는지 확인합니다. GIF의 화면 배경은 내보내기 시점의 정지 화면입니다. |
| 부분 확대 | 샘플 화면에서 부분 확대 도구를 사용하고 확대를 종료합니다. | 선택 영역의 정지 화면을 확대하고 정상 필기로 돌아옵니다. 커서를 따라가는 원형 실시간 확대와 별개입니다. |
| LAN 실시간 화면 | 샘플 화면을 준비하고 자료 공유의 **화면 공유 시작**을 누릅니다. 다른 기기에서 필기 변경을 확인한 뒤 **화면 공유 중지**를 누릅니다. | 선택 모니터 전체가 갱신되고 중지 후 새 화면이 전달되지 않습니다. 자료 다운로드는 계속 사용할 수 있습니다. 음성은 전송하지 않습니다. |
| 실제 마이크·자막 | 마이크를 연결해 장치 새로고침 → 해당 마이크 선택 → Local Whisper와 준비된 모델·CPU 선택 → 시작 순서로 진행합니다. | 마이크 승인 후 발화가 자막으로 보이고 중지·재시작·장치 변경이 작동합니다. 모델 준비가 안 되었으면 장치 탐지까지만 기록합니다. |

이 Mac의 앞선 검사에서는 입력 장치가 발견되지 않았으므로 실제 마이크를 준비해야 합니다. Apple GPU/Neural Engine 가속은 현재 미구현이고 Mac 시스템 오디오 입력도 현재 경로에서 지원하지 않습니다. 클라우드 자막은 API 키와 사용할 제공자가 준비된 뒤 별도로 확인합니다. 키는 결과 기록에 넣지 않습니다.

화면 공유는 선택 모니터의 열린 창과 알림까지 포함합니다. 샘플 화면으로 확인하고 완료 후 중지합니다. 파일 다운로드와 실시간 화면은 각각 결과를 남깁니다.

## 결과 기록

`Open Results.command`로 연 결과 폴더에서 먼저 `latest-summary.txt`를 확인합니다. 각 기본 검사는 `basic-실행시각` 폴더에 결과를 남기며 다시 실행해도 이전 결과를 덮어쓰지 않습니다. 로그인이나 기존 앱 종료 안내로 검사가 시작되지 않았다면, 남아 있는 요약은 이전 실행 결과입니다.

| 파일·폴더 | 내용 |
| --- | --- |
| `latest-summary.txt` | 마지막 기본 검사의 간단한 통과·실패 결과 |
| `basic-실행시각/run-1.json`, `run-2.json` | 1회차와 재실행의 상세 보고서. 1회차 실패 시 2회차 보고서는 없습니다. |
| `basic-실행시각/summary.json` | 두 실행을 합친 결과와 소스 리비전 |
| `basic-실행시각/run-1.log`, `run-2.log` | 앱 실행 로그 |
| `basic-실행시각/exports` | 자동 검사에서 생성한 PNG·GIF |
| `manual-captures` | 수동 확인에서 저장한 PNG·GIF의 기본 위치 |

자동 검사 보고서·로그·샘플 파일을 보관하고 아래 표를 복사해 수동 결과를 추가합니다. 공개 이슈나 문서로 옮길 때 계정·접속 주소·API 키·개인 화면은 포함하지 않습니다.

```text
앱 버전 / 커밋:
macOS 버전 / CPU:
화면 수 / 해상도 / 배율:
실행 경로: 준비 폴더 / DMG에서 복사한 앱
자동 검사 보고서 파일:

항목                 결과(통과/실패/미실시)  증거 파일 또는 재현 순서
툴바 / 도킹
시스템 글꼴 / TTF
설정 12~20 px / 재실행 유지
실제 한글 IME
필기 / 클릭 통과 / 단축키
필기 PNG / 투명 GIF
스포트라이트 밝기 강조
다른 기기 자료 다운로드
전체 화면 캡처(선택)
다른 기기 실시간 화면(선택)
실제 마이크 자막(선택)
DMG 앱 설치 / 실행

실패 시: 조작 순서 → 기대 결과 → 실제 결과 → 오류 문구
```

준비 폴더에서 실행한 결과와 DMG에서 Applications로 복사한 앱의 설치·실행 결과를 구분합니다. 현장 점검 후 모든 공유·자막을 중지하고 필기를 저장한 뒤 앱을 종료합니다.
