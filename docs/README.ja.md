# LayerPen

画面共有・デモ・授業向けの無料オープンソース描画オーバーレイです。選択したモニターに書き込み、描画を残したまま元のアプリを操作できます。

[Windows版をダウンロード](https://github.com/BAEM1N/layerpen/releases) · [English](../README.md) · [한국어](USER-GUIDE.ko.md) · [简体中文](README.zh-CN.md)

## 起動

Windows x64のインストーラーを実行するか、ポータブルZIPを展開して `LayerPen.exe` を起動してください。ビルドは不要です。Microsoft WebView2が必要です。初回公開版は0.1.0で、実行ファイルは未署名です。

設定 → 言語で日本語を選べます。標準ではシステムの言語を使います。日本語・英語・韓国語・簡体字中国語に対応し、変更は全ウィンドウに反映され、次回起動時も保持されます。

## 主な機能

- モニター選択、ペン・蛍光ペン・図形、線単位の消しゴム。
- 選択・移動・サイズ変更、元に戻す・やり直す。
- 横向き・縦向きツールバー、色と太さ、個別ショートカットの設定。
- 静止画の部分拡大と描画、ホワイトボード・黒板、消えるインク。
- PNG保存、描画過程のGIF書き出し。

カーソルのアイコンで下のアプリを操作します。`Ctrl+Shift+D` は描画・マウスの切り替えです。全消去は3秒以内に2回押すと実行され、GIF履歴もリセットされます。

描画とGIF履歴は終了時に失われます。必要な内容は先に書き出してください。拡大とGIFの背景は静止画で、動画録画ではありません。会議ではモニター全体を共有し、参加者に描画が見えることを確認してください。アプリ単体の共有では描画が含まれない場合があります。macOS/Linuxの実行と会議サービスごとの検証は未完了です。

## ソースからビルド

Node.js 22以降、Rust、TauriのOS別依存環境が必要です。

```sh
npm ci
npm test
npm run dev
npm run installer:windows
```
