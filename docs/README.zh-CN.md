# Pointory

用于屏幕共享、演示和教学的免费开源屏幕批注工具。选择一个显示器进行绘图，并在保留批注的同时操作下方应用。

[下载 Windows 版本](https://github.com/BAEM1N/pointory/releases) · [English](../README.md) · [한국어](USER-GUIDE.ko.md) · [日本語](README.ja.md)

## 开始使用

运行 Windows x64 安装程序，或解压便携版 ZIP 后运行 `Pointory.exe`，无需自行编译。需要 Microsoft WebView2。首个公开版本为 0.1.0，可执行文件尚未签名。

在设置 → 语言中选择简体中文。默认跟随系统语言，支持中文简体、英语、韩语和日语。更改会立即应用到所有窗口，并在下次启动时保留。

## 功能

- 选择批注显示器，使用画笔、荧光笔、形状和整笔擦除。
- 选择、移动、缩放批注，以及撤销和重做。
- 横向或纵向工具栏，自定义颜色、粗细和各功能快捷键。
- 冻结画面的局部放大与批注，白板、黑板和渐隐墨迹。
- 保存 PNG 或导出绘图过程的 GIF。

单击鼠标图标可操作下方应用。`Ctrl+Shift+D` 切换绘图和鼠标模式。全部清除需要在三秒内按两次，同时会重置 GIF 记录。

退出应用时批注和 GIF 记录会丢失，请先导出需要的内容。放大和 GIF 使用静态背景，并非视频录制。在线会议时请共享整个显示器，并请参会者确认批注可见；仅共享应用窗口可能不包含批注层。macOS/Linux 运行和各会议服务的端到端兼容性尚未验证。

## 从源码构建

需要 Node.js 22 或更高版本、Rust 和对应操作系统的 Tauri 依赖环境。

```sh
npm ci
npm test
npm run dev
npm run installer:windows
```

参阅[开发指南](DEVELOPMENT.md)。项目代码采用 MIT 许可证，可在公司内部使用；各依赖库保留其原有许可证。
