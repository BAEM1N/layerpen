# OnPen 사용 안내

선택한 모니터에 판서하는 무료 MIT 오픈소스 앱입니다. 강의·온라인 화면 공유·프로그램 시연에 사용할 수 있습니다.

## 설치와 언어

[GitHub Releases](https://github.com/BAEM1N/layerpen/releases)에서 Windows 설치 EXE 또는 포터블 ZIP을 받으세요. 포터블은 압축을 풀고 `OnPen.exe`를 실행합니다. Microsoft WebView2가 필요합니다. 설치파일은 서명되지 않은 베타입니다.

설정 → 언어에서 한국어·영어·일본어·중국어 간체를 선택합니다. 기본값은 시스템 언어이며 지원하지 않는 언어는 영어로 표시합니다. 선택은 모든 창에 즉시 적용되고 다음 실행에도 유지됩니다.

## 기본 사용

1. 설정에서 필기할 모니터를 선택합니다. 화면 식별 버튼으로 번호를 확인할 수 있습니다.
2. 펜·형광펜·직선·사각형·타원을 선택해 그립니다. 색상은 기본 5색과 컬러 피커를 사용하며 기본색은 설정에서 바꿀 수 있습니다.
3. 굵기 버튼으로 5단계 중 선택합니다. 지우개는 닿은 획 전체를 삭제합니다.
4. 커서 아이콘으로 아래 프로그램을 조작합니다. Ctrl+Shift+D는 필기/마우스 전환 단축키이며, Escape도 마우스 모드로 돌아갑니다.
5. 눈 아이콘은 판서를 보관한 채 숨깁니다. 선택 도구로 획 이동·크기 조절을 할 수 있으며 Shift로 비율을 유지합니다.

툴바는 가로·세로로 바꿀 수 있고 점 무늬 손잡이를 드래그해 이동합니다. 도구별 단축키는 설정에서 지정·비활성화할 수 있습니다. 전역 전환 키 이외의 단축키는 앱에 포커스가 있을 때 동작합니다.

## 확대·강조

돋보기로 영역을 드래그해 최대 x6로 확대하거나 한 번 클릭해 x2로 확대합니다. 화면은 정지된 이미지이며 확대 중 영상·스크롤은 갱신되지 않습니다. x2에서 굵기 8로 그리면 원본에는 굵기 4로 저장됩니다. 확대 종료 시 판서는 원래 좌표에 남습니다.

화이트보드·블랙보드는 배경만 바꾸며 판서를 유지합니다. 사라지는 잉크는 설정한 시간이 지난 뒤 없어지고 GIF에도 그 과정이 반영됩니다.

## 저장과 화면 공유

PNG는 화면+판서 또는 투명 판서 레이어로 저장합니다. GIF는 필기·이동·크기 변경·삭제 과정을 정지 배경 위에서 재생하며 영상이나 소리를 녹화하지 않습니다. 저장 위치는 설정에서 선택하고 파일명은 날짜·시간으로 자동 생성합니다.

전체 지우기는 3초 안에 두 번 누릅니다. 현재 모니터의 판서와 GIF 기록을 초기화하며 되돌릴 수 없습니다. 앱 종료 시 판서와 GIF 기록이 사라지므로 필요한 결과는 먼저 내보내세요.

온라인 회의에서는 선택한 모니터 전체를 공유하고, 참석자에게 판서가 보이는지 확인하세요. 앱 창이나 브라우저 탭 공유에는 오버레이가 포함되지 않을 수 있습니다. 회의 서비스별 참석자 화면 검증과 macOS/Linux 실기 검증은 아직 완료되지 않았습니다.

## OnPen v0.1 갱신

설정은 툴바 옆에 붙습니다. 툴바 방향(가로/세로)과 줄 수(1/2/3)를 따로 고르면 총 6가지 배치를 사용할 수 있습니다. 화면보다 긴 경우 툴바를 스크롤합니다. 툴바 끝 X는 앱 종료입니다.

텍스트 글꼴은 시스템 설치 목록에서 선택합니다. TTF 파일 추가로 고른 파일은 앱 설정 폴더에 복사되므로 원본을 이동해도 유지됩니다. 추가한 글꼴은 텍스트 입력 및 PNG/GIF 내보내기에 적용됩니다. 앱 테마와 펜 색상은 별도입니다.
