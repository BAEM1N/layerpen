# Pointory v0.1.0 이름 변경 검증 — 2026-09-09

- Rust 34개, JavaScript UI 29개, Python STT 17개 통과(총 80개). Rust 수강생 페이지용 `browser_fixture` 1개는 기본 자동 실행에서 제외합니다.
- 제품명·패키지명·문서·배포 파일 참조를 Pointory(포인토리)로 갱신하고 내부 식별자 `dev.personal.monitorink`를 유지했습니다.
- 구형 설정의 테마·툴바 방향·펜 굵기·직접 지정한 저장 경로 유지, 가져온 TTF 복사와 `OnPenFont-` 식별자 전환을 테스트했습니다. 기존 설정과 글꼴 파일은 남고, 이미 있는 Pointory 데이터는 덮어쓰지 않습니다.
- `POINTORY_DATA_DIR` 우선순위, 이전 `ONPEN_DATA_DIR`·`MONITOR_INK_DATA_DIR` 호환과 격리 프로필 동작을 테스트했습니다. 기본 캡처 폴더는 Pictures/Pointory로 전환하고 기존 내보내기 파일은 이동하지 않습니다.
- OpenVINO의 완전한 이전 모델 캐시 재사용, 불완전한 캐시 처리, 새 모델의 Pointory 경로와 명시한 캐시 경로의 우선순위를 테스트했습니다. 실제 모델 다운로드·GPU/NPU 추론 대신 모의 다운로드/파이프라인으로 검증한 결과입니다.
- STT 모델 경로·진단 환경변수의 `POINTORY_` 우선순위와 `ONPEN_`·`LAYERPEN_` 호환을 테스트했습니다. 기존 Windows STT 가상환경은 이동하지 않고 원래 경로에서 재사용하도록 구현했습니다.
- Pointory의 한국어·영어 설정, 가로·세로 툴바, 소개 화면, 자막·자료 공유 설정, 스포트라이트 미리보기 캡처를 갱신했습니다. 예제 모니터·글꼴·화면을 사용하는 브라우저 미리보기이며 네이티브 실행 검증을 대신하지 않습니다.
- 실제 Rust localhost `browser_fixture` 서버에서 Pointory 수강생 페이지를 열어 production viewer의 정적 예제 프레임 표시와 선택한 README 다운로드 HTTP 200 응답을 확인하고 화면을 다시 캡처했습니다. 다른 기기 접속이나 실제 모니터 스트리밍을 검증한 결과는 아닙니다.
- Windows Pointory release와 NSIS 설치 EXE 빌드에 성공했습니다. 생성된 NSIS 템플릿의 ProductName `Pointory`, MainBinary `pointory`, 기존 OnPen 등록 키 유지와 `LICENSE.tauri` 포함을 확인했습니다. 포터블 ZIP 무결성 검사도 통과했습니다.
- 기존 `ONPEN_DATA_DIR` 별칭의 격리 프로필로 실제 Pointory를 실행해 새 창 제목·설정 로고, 가로 660×64·세로 64×660 툴바의 15개 기본 버튼, 패널 확장, 도형·색상·굵기 선택, Escape 동작을 확인했습니다.
- 네이티브 앱에서 방향 전환 시 굵기 유지, 필기 표시·숨김, 이전 3줄 설정 무시, 실제 GIF 파일 생성을 확인했습니다.
- README·Wiki·문서의 내부 파일 링크 201개, 패키지 메타데이터 정합성, 패키징 Python 문법과 문서 변경의 `git diff --check`를 확인했습니다.
- **미실시:** 실제 NSIS 이전 설치본 업그레이드·새 설치·제거. 기존 등록 키와 바로가기 갱신 순서는 정적으로 검토했으며 실제 설치 전환 검증으로 간주하지 않습니다. 아래 OnPen 검증 기록 역시 이번 이름 변경 빌드의 결과로 간주하지 않습니다.
- macOS/Linux 실제 실행, 실제 교실 다중 기기 공유, 클라우드 유료 키와 Apple GPU/ANE 검증은 계속 미완료입니다. 도메인 `pointory.app`은 아직 구매·연결하지 않았습니다.

# OnPen v0.1.0 갱신 검증 — 2026-09-09

## 툴바 단순화 갱신

- 가로 660×64, 세로 64×660의 Windows 네이티브 툴바에서 15개 기본 버튼이 모두 표시되는 것 확인.
- 네이티브 패널 확장·축소, 도형 선택, 색상과 굵기, Escape로 패널만 닫기, 방향 전환, 판서 숨김·표시 검증.
- 방향 변경 시 선택 굵기 유지 및 해당 도구의 기본 굵기 변경 시 반영 확인.
- Node 29개, Rust 30개 통과; 구형 줄 수 설정을 무시하면서 사용자 값을 유지하는 회귀 검사 포함.
- 브라우저에서 KR/EN 설정 및 제한된 520px 화면에서도 종료·설정 버튼 접근 확인.
- 툴바의 더보기 → GIF 내보내기로 예제 획이 GIF 파일로 저장되는 것 확인. 삭제된 상태 표시 요소를 참조하던 진행률 오류 수정.
- 새 툴바·패널·설정·README 소개 캡처 갱신. macOS/Linux 네이티브 동작은 아직 미검증.

## 자료 공유·스포트라이트·문서 갱신

- Node 29개 + Rust 29개 + Python STT 12개 = 70개 통과. Rust의 브라우저 예제 서버 테스트 1개는 기본 자동 실행에서 제외합니다.
- Python 기본 환경에는 numpy가 없어 최초 실행이 실패했고, 기존 STT 가상환경으로 다시 실행하여 12개 통과했습니다.
- 실제 loopback HTTP 서버: 선택 파일 응답, 잘못된 Host/주소/경로 차단, 목록에서 제거한 파일의 접근 해제, 서버 종료, 실시간 프레임 중지 검증.
- 실제 브라우저: 공유 페이지와 production viewer script가 예제 JPEG를 가져와 표시하는 것 확인. 샘플 파일 다운로드 응답은 Rust 통합 테스트로 확인.
- 스포트라이트 확대 영역의 모니터 가장자리 제한 테스트. 실제 설정 UI와 밝기 강조 표시 코드를 예제 화면에서 캡처.
- README 및 Wiki 내부 파일 링크 181개와 JPEG 파일 시그니처 확인. 한국어·영어 각각 11개 기능 안내 작성.
- Windows release 및 NSIS 설치 EXE 빌드. 포터블 ZIP 무결성과 릴리스 SHA-256 생성.
- **미검증:** 이번 빌드의 네이티브 스포트라이트 사용감, 실제 화면 캡처 전송, 다른 기기/학교 Wi-Fi 접속, 다수 수강생 부하, 최신 설치본 설치·제거 재검증. 이전 설치 테스트를 이번 갱신의 검증으로 간주하지 않습니다.
- macOS/Linux 실제 실행과 클라우드 유료 키 검증은 계속 미완료입니다. 스크린샷의 예제 데이터는 해당 검증을 대신하지 않습니다.

이전 OnPen 갱신 검증:

- Node 29개, Rust 25개, Python STT 12개 통과 (총 66개).
- 글꼴 파일 검증: 시스템 설치 글꼴 파싱, TTF 데이터 검증, 잘못된 파일 및 경로 ID 거부.
- 툴바 가로·세로 크기 및 패널 확장, 구형 줄 수 설정의 방향·사용자 값 유지 테스트.
- Rust 도킹 테스트: 음수 모니터 좌표, 오른쪽 공간 부족 시 왼쪽 이동, 아래 공간 부족 시 위쪽 배치, 작은 작업 영역에서 클램핑.
- 이번 갱신은 Windows 대상. Mac/Linux 실제 실행, Apple GPU/ANE, 유료 API 실연결은 미검증.
- 자막은 별도 Python 환경과 모델 다운로드가 필요한 실험 기능이며 실행 파일만으로 STT 의존성이 설치되지 않습니다.

# LayerPen v0.1.0 검증 기록

검증일: 2026-09-07~08. Windows x64에서 로컬로 빌드했습니다.

- JavaScript 테스트 25개와 Rust 테스트 19개 통과. 기본 캡처 폴더 전환과 사용자 지정 경로 보존 검사를 포함합니다.
- NSIS 설치형 EXE 빌드 및 별도 테스트 디렉터리에 설치 성공.
- 실행 파일과 설치 파일의 제품명 LayerPen, 버전 0.1.0 확인.
- 실제 설치 앱에서 영어, 일본어, 중국어 간체, 한국어 전환 및 설정 저장 확인.
- 설정·도구 모음·오버레이 간 언어 동기화와 실제 그리기, 마우스 모드 복귀 확인.
- 브라우저 회귀 검사에서 네 언어의 설정과 도구 모음, 좁은 설정 창의 레이아웃 확인.
- 배포용 포터블 ZIP을 풀고 `LayerPen.exe`를 실행하여 영역 확대, 정규 좌표의 그리기·이동·지우기, 확대 PNG 및 실제 화면 내보내기 확인.

macOS/Linux의 실제 실행, 혼합 DPI의 다양한 모니터 구성, 화상회의 상대방 화면에서의 표시까지 검증한 것은 아닙니다. 설치 파일은 코드 서명되지 않았습니다.
